Get the available videos for a movie, including trailers, teasers, featurettes, and clips.

```ts
async videos(params: MovieVideosParams): Promise<MovieVideos>
```

> **TMDB Reference:** [Movie Videos](https://developer.themoviedb.org/reference/movie-videos)

## Parameters

| Name                     | Type                                                | Required | Description                                                                                                                                             |
| ------------------------ | --------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `movie_id`               | `number`                                            | ✅       | TMDB movie identifier.                                                                                                                                  |
| `language`               | [`Language`](/docs/types/options/language#language) | ❌       | Language for localized results. Defaults to `en-US`.                                                                                                    |
| `include_video_language` | `string`                                            | ❌       | Comma-separated ISO 639-1 codes of extra video languages to include (e.g. `"it,en,null"`). Without it, only videos tagged with `language` are returned. |

By default TMDB only returns videos tagged with `language`, which is often nothing for non-English languages. Pass `include_video_language` to widen the set, e.g. `"it,en,null"` for Italian, English and untagged videos.

## Returns

[`MovieVideos`](/docs/types/movies#movievideos)

## Example

```ts
const { results } = await tmdb.movies.videos({ movie_id: 550 });

const trailer = results.find((v) => v.type === "Trailer");
console.log(`https://www.youtube.com/watch?v=${trailer?.key}`);

// Italian videos plus the English trailers
const { results: all } = await tmdb.movies.videos({ movie_id: 550, language: "it-IT", include_video_language: "it,en" });
```
